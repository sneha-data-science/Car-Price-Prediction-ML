# Car Price Prediction using Machine Learning

## Project Overview
This project predicts the price of cars using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset
Car Price Prediction Dataset (CarPrice_Assignment.csv).

## Machine Learning Algorithm
Linear Regression

## Input Features
- Engine Size
- Horsepower
- Curb Weight

## Output
Predicted Car Price.

## Model Evaluation
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R2 Score

## Conclusion
This project demonstrates how Machine Learning can be used to predict car prices based on different car features.# Car-Price-Prediction-ML
Car Price Prediction using Machine Learning and Linear Regression. This project predicts car prices based on engine size, horsepower, and curb weight.
